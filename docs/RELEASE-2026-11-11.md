- The contract's main record (439 bytes under the `STATE` key) has the same SHA-256 before and after: `7f58a370a1f2a592ee78830bfb093c1c42b1cbd6d7040692a94aedb700470ec6`.

- All 28 Bonds have the same stored record and the same owner.
- Storage use went from 445,208 to 448,014 bytes. The 2,806 bytes are the larger code and nothing else.
- New in the answers: `get_stats` now reports `feast`, and `get_feast` answers for any week. Both say no memecoin is feasting, which is right for the launch week. The first Feast is crowned at 2026-11-12 00:00 UTC, and the first week in which the rule can change who feasts starts on 2026-11-19.
